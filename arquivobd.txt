=====================================
Criar Executável
=====================================
pyinstaller --noconsole --onefile --name="ControleFinanceiro" --collect-all customtkinter main.py

pyinstaller --noconsole --onefile --name="ControleFinanceiro" --icon="financeiro.ico" --collect-all customtkinter main.py



O que significam esses comandos?
--noconsole: Oculta aquela janela preta do prompt de comando. O programa abrirá apenas a interface visual do CustomTkinter.
--onefile: Junta todo o seu projeto e bibliotecas em um único arquivo .exe.
--collect-all customtkinter: Força o PyInstaller a copiar todos os arquivos internos de temas escuros/claros da biblioteca visual.
    Após terminar o processo, duas novas pastas serão criadas: build e dist. Entre na pasta dist e lá estará o seu arquivo ControleFinanceiro.exe 
    pronto para ser movido para qualquer lugar do seu computador e rodar direto.


Passo 3: Gerando a Versão para o LinuxAbra o terminal do seu sistema Linux (ou uma máquina virtual) dentro da pasta do projeto e siga estes passos:Garanta que o Python do Linux tenha o gerenciador de pacotes e o Tkinter instalados. No Ubuntu/Debian/Mint, digite:bashsudo apt update
sudo apt install python3-pip python3-tk -y
Use o código com cuidado.Instale as dependências do seu projeto e o PyInstaller no ambiente Linux:bashpip install customtkinter sqlmodel matplotlib pyinstaller
Use o código com cuidado.Execute o comando de compilação idêntico ao do Windows:bashpyinstaller --noconsole --onefile --name="ControleFinanceiro" --collect-all customtkinter main.py
Use o código com cuidado.O processo gerará um arquivo executável binário dentro da pasta dist. Para rodar o programa no Linux pelo terminal, navegue até a pasta dist e dê permissão de execução ao arquivo:bashcd dist
chmod +x ControleFinanceiro
./ControleFinanceiro
Use o código com cuidado.(No Linux, você também pode dar dois cliques no arquivo gerado para abrir a interface gráfica diretamente, desde que o gerenciador de janelas permita executáveis de terceiros).
